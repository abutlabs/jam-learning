The Mutation Lab

The curated vectors prove lasair imports honest blocks. The official fuzzer sends corrupted ones — and has no answer key, because the only correct response to garbage is the same every time: reject it, change nothing, stay alive. We call that the trilogy. This lab is lasair's own examiner: it takes a block we know is valid, breaks it one way at a time, and checks the trilogy holds.

Why nothing gets through

A block is wrapped in layered cryptographic commitments. A mutation without a validator's signing key always breaks one of them — there is no gap to slip through. The lab proves it by trying.

Run it yourself

The engine lives in lasair's replay driver (lasair's source is not public yet, so for now this shows how the lab is run). One pass mutates every block in a family; the soak loops with fresh seeds for hours. 

# one pass over a family, with a per-class report
dune exec bin/fuzz_driver.exe -- \
  --mutate vectors/traces/fuzzy \
  --mutate-report /tmp/mutation.json

# soak: loop every family for 30 minutes, fresh seeds each round
dune exec bin/fuzz_driver.exe -- --mutate-soak 30 \
  --mutate vectors/traces/fallback \
  --mutate vectors/traces/safrole \
  --mutate vectors/traces/fuzzy
